# VAULT — Smart Contract Security Landing Page
A clean, responsive Web3-themed landing page built with pure HTML and CSS. 


# About
VAULT is a conceptual smart contract security platform designed to help Web3 developers analyze, test, and secure their contracts before deployment. The platform focuses on vulnerability detection, risk monitoring, and contract integrity giving developers confidence before going live on-chain. 

# Built With
	•	HTML5
	•	CSS3 (Custom Properties, Flexbox, Grid, Media Queries)
	•	Google Fonts — Space Grotesk + Inter

# Features
	•	Sticky navigation bar
	•	Hero section with CTAs
	•	Features grid with hover effects
	•	Stats section
	•	Call-to-action section
	•	Responsive layout (mobile + desktop)
